# micro-38 Examples and Boundaries

## Decision Variable
whether the expression leads the listener to a false inference

## Route Signal
Route here when a true statement, partial statement, or framing choice is judged by whether it misleads the listener into a false belief.

## Hard Boundary
- The decision is whether the listener is led to a false belief, not whether the words are factually true; the bare true-or-false judgment is the truth-status capability (micro-37).
- Cooperative implicatures the listener is meant to recover correctly do not count; this unit fires only when the inference the listener draws is FALSE, in contrast with the conversational-implicature capability (micro-36).
- The unit judges the communicative effect on the listener, not the speaker's strategic reason for choosing those words; that reason is the speaker-motivation capability (micro-39).

## Shortcut To Avoid
- Do not assume 'true sentence' means 'not misleading'.
- Do not over-focus on what was said; check what a normal listener would infer.
- Do not collapse selective omission into simple lying.

## Common Failure Modes
- Answering the bare truth/lie question instead of the misleading-effect question.
- Assuming a literally true sentence cannot mislead, and therefore clearing it.
- Treating any unstated meaning as ordinary implicature even when the inference the listener draws is false.
- Ignoring the omitted or de-emphasized fact that flips the listener's belief.
- Jumping to the speaker's intent or morality when the unit only asks about the effect on the listener.

## Minimal Pair
- Case: An antique dealer truthfully tells a buyer the jade piece is 'a star product that draws many collectors,' while staying silent that it is a modern replica, not the antique relic the buyer believes she is paying for. | Why: In scope: each stated phrase can be true, yet the selective silence steers the buyer to a false belief about the object's age and value — a true-but-misleading expression.
- Case: Lily breaks her mother's vase, then says 'The dog knocked it over,' when in fact no dog was involved. | Why: Out of scope: the statement is flatly false, so the issue is plain lying, which routes to the truth-status capability (micro-37) — not a true statement producing a false inference.

## Boundary Stress Test
- If the sentence is true and a reasonable listener would NOT infer anything false from it, do not use this unit (no false belief is induced).
- If the question is just 'Did the speaker lie?' or 'Is it true?', route to the truth-status capability (micro-37) unless the task explicitly asks about the misleading effect.
- If a true statement misleads only because the listener draws a correct intended inference, the case is cooperative implicature, not misleading — route to the conversational-implicature capability (micro-36).
- If the focus is the speaker's reason for the wording rather than the false impression it creates, route to the speaker-motivation capability (micro-39).

## Generalization Note
This unit covers deceptive framing, selective disclosure, and truth-preserving misleading communication across social, professional, and everyday contexts — the common thread is a literally-true or partly-true expression that leaves the listener with a false belief.
