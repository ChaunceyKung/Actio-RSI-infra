# Commitment Priority

## Use When
- Use when a binding prior commitment exists — a promise already made, a task already underway, a scheduled appointment, or a duty someone is counting on — and it constrains what the character can do.
- Use when a new invitation, temptation, or desire arrives but a standing obligation determines what is honored first (and often the character returns to it afterward).
- Use when the answer turns on which commitment is more binding, not on which goal is intrinsically more attractive.

## Do Not Use When
- Do not use when no binding prior promise, ongoing task, schedule, or duty exists and two free desires simply compete; that is free weighing of rival goals (Goal-Conflict Arbitration, micro-25).
- Do not use when one goal is merely a step done in order to reach another (means-end nesting); that is Goal Hierarchy (micro-21).
- Do not use when the question asks what the character will physically do next from belief and goal; that is Action Prediction (micro-23).
- Do not use when the question asks why someone acted, looked, or gestured; that is Intention Recognition (micro-22).
- Do not use when the main issue is emotion, persuasion, or a social-norm violation rather than ranking commitments.

## Decision Variable
the priority order among commitments: which binding promise, ongoing task, or obligation a character must honor first

## Trigger Checklist
- A binding prior element is present: a promise already made, a task already in progress, a fixed schedule, or someone depending on the character.
- A new option (invitation, desire, temptation) competes with that binding element.
- The question is which one should be honored first, not which goal is more enjoyable.
- Remove the binding commitment and the answer would change — the commitment, not raw preference, decides.

## Workflow
- Identify the binding prior element: what was promised, already started, scheduled, or relied upon by someone else.
- Identify the competing new option (invitation, desire, or temptation) and confirm it has no stronger binding status.
- Apply the rule: the binding commitment is honored first unless the scene states an explicit override (emergency, cancellation, or permission to reschedule).
- Choose the option that honors the highest-priority commitment; if the character resumes a paused plan afterward, that resumption confirms the original commitment held.

## Special Case
**New request versus a plan already in motion**: When a character is mid-task or has a standing plan and a new request arrives, the binding obligation is honored and the original plan is resumed afterward, unless an explicit override (emergency, cancellation, permission) is stated.

Scene: David is loosely planning a casual BBQ for friends this weekend, with no fixed time set yet. The neighborhood elderly then tell him the community park's public facilities are broken and they are depending on his help to repair them today. He postpones the BBQ and goes to help.
Question: What does David do after he finishes repairing the facilities?
Answer logic: The repair outranks the BBQ because the elderly are depending on David and the facilities are needed today, whereas the BBQ is only a loose plan with no fixed time and can be moved. So the dependency-backed task is honored first; his own BBQ was merely postponed, not abandoned, and once the repair is done he reorganizes it. The more binding obligation decided the order; the flexible plan resumes.

## Boundary Exit Rule
- Exit to the free-weighing-of-rival-goals capability if there is NO binding promise, ongoing task, or schedule and two desires simply compete (Goal-Conflict Arbitration, micro-25).
- Exit to the means-end-structure capability if one goal is merely a step done in order to reach another, rather than a binding obligation that decides order (Goal Hierarchy, micro-21).
- Exit to the next-action-prediction capability if the question asks what the character will physically do next rather than which plan has priority (Action Prediction, micro-23).
- Exit to the immediate-purpose-of-a-behavior capability if the scene asks why the person is doing something (Intention Recognition, micro-22).
- Exit to a persuasion or repair capability if the main issue is how to talk about the conflict, not which plan to honor.
