# micro-21 Examples and Boundaries

## Decision Variable
the means-end (nesting) relation among goals: which goal is superordinate (the end) and which is subordinate (a step serving it)

## Route Signal
Use this unit when one goal is done in order to reach another and you must name which is the end and which is the step. If instead two goals compete with no nesting, route elsewhere.

## Hard Boundary
- Hierarchy = means-end STRUCTURE (A serves B); not which of two competing goals wins, which is free weighing of rival goals (Goal-Conflict Arbitration, micro-25).
- Hierarchy is structural level; it is not the order forced by a binding promise or schedule, which is the binding-commitment capability (Commitment Priority, micro-24).
- Hierarchy is about goal level, not the immediate purpose of one present behavior, which is Intention Recognition (micro-22).
- Hierarchy is goal nesting, not the next observable action, which is Action Prediction (micro-23).

## Shortcut To Avoid
- Do not treat the goal mentioned first, or the action happening first in time, as the higher-level goal; order in the text or timeline is not level.
- Do not treat the subgoal the character is currently busy with as the main aim; the end goal is the original want it serves.
- Do not collapse a means-end chain into a conflict; here the subgoal advances the end goal, it does not compete with it.

## Common Failure Modes
- Confusing a subtask the character is doing right now with the main objective it serves.
- Reading a means-end chain as a goal conflict and trying to pick a winner.
- Assuming the character abandons the original want once they start the detour task, when in fact they resume it.
- Equating long-term with 'more preferred' or short-term with 'less important' without textual support.

## Minimal Pair
- Case: Tom wants to buy things; an aunt offers money if he picks apples, so he picks apples first. Question: what does he do afterward? | Why: Picking apples is a subordinate step serving the end goal of buying things; recognizing the nesting predicts he resumes the original want. In-scope means-end structure.
- Case: Li Hua loves outdoor adventure; Wang Fang prefers the quiet library; they must pick one place for the weekend. Question: where do they go? | Why: Two goals compete head-to-head with no nesting (neither serves the other), so the answer is a weighing of rival goals, not a hierarchy. Routes to the free-weighing capability (Goal-Conflict Arbitration, micro-25).

## Boundary Stress Test
- If two goals compete for the same slot and the answer names a winner, this is weighing of rival goals, not hierarchy.
- If a binding promise or schedule is what sets the order, this is the binding-commitment capability, not hierarchy.
- If the story asks what the person will physically do next as the endpoint, route to action prediction even if goals are present.
- If the only clue that one goal is 'higher' is that it happens earlier in time, that is not evidence of level.

## Generalization Note
Use this unit only for means-end structure among goals (which goal serves which). It does not pick a winner among competing goals, does not resolve binding commitments, and does not output the next action.
