# macro-01 Examples and Boundaries

## Decision Variable
where or how a character will act based on a false belief

## Route Signal
A character will search or act according to an outdated belief because a relevant change happened outside their awareness.

## Hard Boundary
- Current reality alone is not the answer when the question asks what the character will do.
- The macro requires first-order belief by the target character, not nested belief about another mind.
- If the target character received reliable updating evidence, the belief is no longer false and the classic false-belief route should not be used.
- If no action or belief-guided behavior is asked, this may be a knowledge, appearance-reality, or factual-recall problem instead.

## Shortcut To Avoid
- Do not answer with the real current location just because the narrator reveals it.
- Do not assume a character knows a change simply because the reader knows it.
- Do not upgrade a character's belief unless the scene gives that character perceptual or communicative access.
- Do not treat every hidden-object scene as false belief; the key is the target character's outdated belief.

## Common Failure Modes
- Reality bias (the dominant error): picking the object's true current location because the narrator stated it, instead of the character's believed location. The correct false-belief answer is the ORIGINAL place, which differs from where the object really is.
- Omniscience leak: crediting the target character with the change just because the reader, narrator, or another character knows it, when the target had no perceptual or communicative access.
- Nested-mind confusion: treating a second-order question ('where does A think B looks') as if it were about a single character; a nested question must be solved by modeling the inner person's belief first, then the outer person's belief about it.
- Appearance-reality drift: answering what the object really is instead of where or what the character believes; a looks-versus-is or misidentified-object question is solved by tracking true identity against the misleading appearance, not by this belief-driven-action procedure.
- Over-updating: treating ambiguous noise, a glimpse of someone approaching, or an irrelevant coincidence as proof the character learned of the change, and wrongly switching to the real location.

## Minimal Pair
- Case: Nadia leaves the bedroom; while she is gone Wei moves the cabbage from the handbag to the backpack. Q: where does Nadia look for the cabbage? (in-scope: a single character's own false belief) | Why: First-order false-belief search after an unseen move. Answer is the handbag (original place), Nadia's outdated belief. Decisive variable: the question is about Nadia's OWN action.
- Case: Same scene. Q: where does Wei think Nadia looks for the cabbage? (out-of-scope: one character modeling another's belief) | Why: Near miss differing in ONE variable: the question nests one mind inside another (Wei modeling Nadia), so it is a second-order belief problem and must be solved by modeling Nadia's belief first and then Wei's belief about it, even though the answer also lands on the handbag. Decide by the question's structure, not the answer it lands on.
- Case: Same scene, but Nadia sees Wei make the move through the open doorway before she returns. Q: where does Nadia look? (out-of-scope: belief no longer false) | Why: Near miss differing in ONE variable: Nadia now has perceptual access to the change, so her belief updates and she looks in the backpack. The classic false-belief default does not apply once the target witnessed or was reliably told.

## Boundary Stress Test
- If the character was physically absent but received a clear message about the move, do not preserve the old belief.
- If the character saw only someone approach the object but not actually move it, decide whether that evidence is enough to update belief by reasoning explicitly about sensory access: a partial glimpse that does not reveal the new location usually leaves the old belief in place.
- If the question asks where another person thinks the target will search, treat it as a second-order belief problem: model the target's belief first, then the other person's belief about it.
- If the question asks what the container really holds despite a misleading label, treat it as an appearance-versus-reality problem and report the true contents, unless an action driven by a character's false belief is also asked.

## Generalization Note
This macro generalizes beyond toy-location puzzles to any scene where action follows an outdated mental model: searching an old folder path, going to a previous meeting room, contacting an old phone number, using an unchanged plan after a silent schedule change, or expecting someone at a location they no longer occupy.
